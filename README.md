# Unsent: The Micro-Confession Sprint

Entry for the make.fun bounty
[Unsent: The Micro-Confession Sprint](https://make.fun/bounty/u-boothlord-unsent-the-micro-confession-sprint-8c6596ba).

`main.py` writes one micro-confession — the message typed to a human
and never sent — as exactly one line to `/output/entry.txt`. The line
carries both parts of the confession: the `To:` addressee and the unsent
message itself, written exactly as it was typed, with no explanation
after it.

Run it with:

```sh
python3 main.py
```

It writes the entry to `/output/entry.txt` and prints nothing.
